Web Technology

HTML stands for HyperText Markup Language. It is used to design web pages using a markup language. HTML defines the structure of web pages and allows browsers to display text, images, links, and other content.

C Programming

C is a procedural programming language. It was initially developed by Dennis Ritchie as a system programming language. C provides low-level memory access and is suitable for system programming and compiler development.

Java

Java is one of the most popular programming languages. Java is object-oriented and its code is compiled into bytecode which runs on the Java Virtual Machine (JVM).

Web Development

Modern web development combines HTML, CSS and JavaScript to create responsive, interactive and user-friendly websites.
